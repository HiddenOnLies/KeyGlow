# Theme credits

The `theme-*.json` profiles in this folder are generated by `tools/make_theme_profiles.py`
from the color palettes below. Colors are brightened where needed so they show on LEDs.
Each source is used under the MIT License, reproduced in full at the end of this file.

| Source | Profiles | Repository |
|---|---|---|
| Catppuccin | 8 | https://github.com/catppuccin/palette |
| Dracula | 2 | https://github.com/dracula/dracula-theme |
| Nord | 2 | https://github.com/nordtheme/nord |
| Tinted | 227 | https://github.com/tinted-theming/schemes |
