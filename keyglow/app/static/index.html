      Connect your keyboard

      KeyGlow talks to your keyboard through OpenRGB, a free program that supports hundreds of devices.

      1. Install OpenRGB
      2. Start OpenRGB with its SDK serverKeyGlow does it for you when OpenRGB is installed.
      3. Close other RGB softwareNGENUITY, iCUE, Synapse, Armoury Crate… Two programs writing to the keyboard fight each other.
